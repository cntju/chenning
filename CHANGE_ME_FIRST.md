# Change these first

Before publishing, edit the following:

1. `_config.yml`
   - `email`
   - `url` → `https://YOUR_GITHUB_USERNAME.github.io`
   - `links.github`
   - ORCID / LinkedIn / ResearchGate if desired

2. Portrait
   - add your real photo as `images/profile.jpg`
   - change `photo` in `_config.yml` to `/images/profile.jpg`

3. CV
   - add your PDF as `files/Chen_Ning_CV.pdf`
   - or change the path in `_config.yml`

4. Publications
   - edit `_data/publications.yml`
   - the starter includes only representative entries; replace them with complete citations and links

5. News
   - edit `_data/news.yml`

6. People
   - edit `_data/people.yml` as students/collaborators join

7. Recruitment wording
   - `_pages/join.md` is ready to use, but update any programme-specific admission/funding information once confirmed.
